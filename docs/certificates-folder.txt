Put your own certificate images in this folder, then double-click "Deploy Portfolio.cmd" on the Desktop.

The website shows these as a framed certificate wall in the Credentials section. Nothing shows if the folder is empty.

Naming: the file name becomes the caption under the photo.
  google-project-management.jpg    ->  Google project management
  photovoltaic-systems-dtu.jpg     ->  Photovoltaic systems DTU
  01-solar-pv-design.jpg           ->  Solar PV design          (a number at the start only sets the order)

Accepted: .jpg .jpeg .png .webp .avif
Tip: screenshots of the certificates from your LinkedIn profile work fine. Crop out the browser
chrome so only the certificate is visible.
