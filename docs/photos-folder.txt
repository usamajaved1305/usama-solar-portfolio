Put your own site photos in this folder, then double-click "Deploy Portfolio.cmd" on the Desktop.

The website builds a "From site" gallery from whatever is in here. Nothing shows if the folder is empty.

Naming: the file name becomes the caption under the photo.
  150-kwp-factory-rooftop.jpg      ->  150 kWp factory rooftop
  inverter-commissioning.jpg       ->  Inverter commissioning
  01-rooftop-mounting-rails.jpg    ->  Rooftop mounting rails   (a number at the start only sets the order)

Accepted: .jpg .jpeg .png .webp .avif
Tips: landscape photos look best; keep each file under about 2 MB; avoid photos that show
client names, addresses or faces you do not have permission to publish.
